# Композиция сцены: правила, зоны, аудит (v1.5)

Этот документ фиксирует **правила, по которым раскладываются спрайты, текст и HUD**,
и протокол, которым это проверяется. Появился он потому, что в версиях 1.3–1.4
сцена «наезжала» сама на себя: облачка реплик закрывали титр и персонажей,
подсказка по управлению уходила под сани, Дед Мороз стоял посреди улицы в актах,
а по экрану летали золотые «★ 0» (снег рисовался картинкой HUD).

## 1. Зоны сцены (сцена 480×360, координаты −240…240 / −180…180)

```
 y
 180 ┌──────────────────────────── верхний край ────────────────────────────┐
     │  HUD: ♥♥♥ (−196,130)        ★ счёт (140,126)        часы (196,126)    │  y ≥ 112
 112 ├──────────────────────────────────────────────────────────────────────┤
     │                                                                      │
     │            ИГРОВАЯ ЗОНА: актёры, звёзды, сугробы, ёлки                │
     │            ноги персонажей — на y = −134                             │
     │                                                                      │
−136 ├──────────────────────────────────────────────────────────────────────┤
     │  ПЛАШКА: подсказки актов и субтитры реплик (−157, высота 42)          │  −136…−178
−178 └──────────────────────────────────────────────────────────────────────┘
```

Жёсткие правила:

1. **Ничто из актёров не заходит ниже y = −136** (кроме частиц: снег, искры,
   снаряды-снежки). Поэтому «пол» поднят: `GROUND = −80` — у Милы рисунок смещён
   вниз внутри полотна 440×440, её копыта оказываются ровно на −133.8.
2. **Весь текст внизу — один спрайт «Плашка»** в одной точке (−157, размер 100).
   Подсказка акта и субтитр реплики физически не могут наехать друг на друга,
   потому что это одна и та же картинка в одном и том же месте.
3. **Титры не пересекаются с HUD и друг с другом**: титр пролога (0,58),
   «С НОВЫМ 2027 ГОДОМ!» (0,124), «2027» (0,64), подпись «Козочка Мила…» (0,6).
4. **Облачков `say` в проекте нет.** Голос идёт из mp3, текст — субтитром.
5. Персонажи, которые не участвуют в акте, **скрыты**, а не «стоят в стороне».

«2027»/фейерверк → кнопки → затемнение.

## 4. Аудит композиции (объективная проверка)

```bash
cd tools && node run_vm.js ../dist/Poslednyaya_posylka.sb3 frames ../dist/frames.json
cd .. && PYTHONPATH=tools/vendor python3 tools/art/frames.py
```

`run_vm.js frames` прогоняет `.sb3` в настоящей scratch-vm и снимает состояние
сцены в 12 ключевых моментах (позиция, костюм, размер, поворот, призрачность).
`frames.py` собирает кадры **ассетами из самого .sb3** и печатает отчёт:

```
кадров: 12 -> art/mock/frames
НАЛОЖЕНИЙ НЕТ: текст, HUD и актёры разведены по своим зонам
```

Проверяется три вещи:
1. текстовые элементы (титр, плашка, «2027», подпись, кнопки, HUD) не пересекаются
   между собой — по **непрозрачным** областям картинок, а не по прямоугольникам;
2. никто из актёров не залезает на плашку субтитров;
3. никто из актёров не заходит в верхнюю полосу HUD.

Картинки — `art/mock/frames/*.jpg`, общий лист — `art/mock/_все_кадры.jpg`.
`tools/art/mock.py` оставлен как «дизайнерский» вариант тех же кадров
(`art/mock/_макеты_дизайна.jpg`), но авторитетны именно настоящие кадры.

## 5. Если правите композицию

1. Меняйте координаты в `tools/sb3/game.py` (единственный источник истины).
2. Пересоберите: `PYTHONPATH=tools/vendor python3 tools/build_game.py`.
3. Прогоните аудит (команды выше) — отчёт должен остаться «НАЛОЖЕНИЙ НЕТ».
4. При необходимости обновите `tools/art/mock.py` (он рисует те же кадры вручную).
