## Как играть
Подробная инструкция от запуска до финала — `docs/07-kak-igrat.md`.
Кратко: зелёный флаг → пролог → акт 1 (ПРОБЕЛ, собрать 5 звёзд) → акт 2 (↑ ↓, ещё 5 звёзд) →
акт 3 (← → и ПРОБЕЛ, продержаться 20 секунд) → победа или «Ещё раз».

## Быстрый старт
```bash
./tools/setup.sh                      # pillow, numpy, lameenc, mutagen, scratch-parser
python3 tools/art/pipeline.py         # фоны и спрайты (хромакей -> RGBA)
python3 tools/art/ui.py               # титры, HUD, кнопки, заглушки
python3 tools/audio/make_music.py     # саундтрек
python3 tools/audio/make_foley.py     # фоли
python3 tools/build_game.py           # сборка + валидация dist/*.sb3
python3 tools/art/mock.py             # макеты кадров art/mock/
```
Внимание: python-скрипты запускать с `PYTHONPATH=tools/vendor`.

## Макеты кадров
`art/mock/_все_кадры.jpg` — пролог, три акта, победа и проигрыш, собранные из настоящих ассетов.

## Структура репозитория
```
docs/     проектная документация (условия, концепции, техника, звук, план)
art/
  koncepty/   концепт-арт трёх вариантов + лист персонажей
  sprites/    игровые спрайты (PNG RGBA, без фона)
  backgrounds/ фоны и слои параллакса
audio/
  music/  оригинальные темы
  foley/  фоли-эффекты
  voice/  озвучка диалогов
tools/    пайплайн ассетов, генератор project.json, валидация
dist/     готовый .sb3 для сдачи
```
